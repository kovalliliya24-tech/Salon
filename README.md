# Telegram Bot for Beauty Salon

Telegram bot designed to simplify appointment booking and customer communication for beauty salons.

<sub>This is a demo version, so all services, staff names, prices, and other information are fictional.</sub>

## Features

- Online appointment booking
- Choice of service, staff member, date, and time
- Real-time availability checking
- Double-booking protection
- Automatic appointment reminders
- Customer ratings and reviews
- Admin panel
- Salon statistics

## Technologies

- Python
- Aiogram
- SQLite
- APScheduler
