# Telegram Bot for Beauty Salon

Telegram-бот для автоматизації запису клієнтів у салон краси.

## Функції

- Онлайн-запис на послуги
- Вибір майстра, дати та часу
- Перевірка вільних годин
- Захист від подвійного бронювання
- Автоматичні нагадування
- Оцінки та відгуки клієнтів
- Адмін-панель
- Статистика салону

## Технології

- Python
- Aiogram
- SQLite
- APScheduler

## Запуск

```bash
pip install -r requirements.txt
